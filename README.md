# Delivery Interaction Customer Satisfaction

This example simulates a delivery professional's interaction with a customer when a problem arises. It demonstrates how different choices in communication and problem-solving directly impact customer satisfaction, highlighting the human factor in delivery services as discussed in the article.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py` and follow the prompts.
